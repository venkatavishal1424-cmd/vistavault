# VistaVault

VistaVault will help curious people search and discover images by place, subject, or mood. Its warm paper and forest-green palette gives the gallery the feeling of a printed field guide rather than a generic search page. A row of quick-pick topic chips offers a few starting points, while the empty-state panel makes it clear where a search will lead. The responsive gallery uses CSS Grid so future image cards can adapt from phones to wide screens.
